## Features Implemented

This project demonstrates the following features:

- **Entity Framework Core**: Implemented database access and management using EF Core.  
- **OAuth / OpenID Connect**: Integrated authentication and authorization using OAuth 2.0 and OpenID Connect protocols.

The implementation follows the guidance provided in the following YouTube tutorial:

[YouTube Tutorial: EF Core and OAuth/OpenID Connect](https://www.youtube.com/watch?v=SZTsdOpEb8M&list=PLEajeS6qEFryLDsBmIHQi0cnmhWf3-BtA&index=9)
